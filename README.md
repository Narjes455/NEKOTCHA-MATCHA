# ركن نيكوتشا 🍵🐈

نسخة تجريبية لفكرة مقترحة لمتجر **NEKOTCHA MATCHA**: بطاقة QR داخل كل طلب، يمسحها العميل ويدخل صفحة خاصة فيه.

## صفحة العميل
- **حضّر كوبك:** يختار الصنف اللي اشتراه وطريقة الشرب (ساخنة، مثلجة، لاتيه)، وتطلع له الكمية والماء والحرارة والخطوات، مع مؤقّت للخفق.
- **متى تخلص علبتك؟** يحدد كم كوب يشرب بالأسبوع، والصفحة تحسب التاريخ التقريبي وتعطيه زر إعادة الطلب من المتجر.
- **أختام القطة:** كل طلب يضيف ختم، وبعد ٦ أختام هدية.

## لوحة صاحب المتجر
- قائمة العملاء مرتّبة حسب أقرب علبة تخلص.
- زر «جهّز عرض» ينسخ رسالة جاهزة يرسلها للعميل.
- إضافة صنف جديد بكميته وحرارته، ويظهر مباشرة في صفحة العميل.

> كل الأسماء والأرقام في هذي النسخة أمثلة للعرض فقط.

## التشغيل
صفحة واحدة بدون أي مكتبات: افتح `index.html` في المتصفح، أو انشرها على GitHub Pages.
لفتح لوحة صاحب المتجر مباشرة أضف `#owner` في آخر الرابط.
